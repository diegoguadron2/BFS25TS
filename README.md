# Siman Clone - Landing Page E-Commerce

## 📌 Descripción
Réplica responsiva de la página principal de Siman (tienda departamental), desarrollada como práctica de maquetación web moderna. Incluye:

- Carrusel promocional con autoplay
- Grid de productos responsive
- Efectos hover interactivos
- Diseño mobile-first

## ✨ Features
- **Responsive Design** (Mobile ↔ Desktop)
- **Optimización de Imágenes** (WebP + Lazy Load)
- **Bootstrap Components**:
  - Navbar togglable
  - Carousel con controles
  - Card groups responsive
- **Efectos Visuales**:
  - Hover en productos
  - Transiciones suaves
  - Sombras y bordes
